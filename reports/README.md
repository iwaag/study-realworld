# Reports

One subdirectory per source, named by that source's id (see
`../sources/INDEX.md`). Each `reports/<source-id>/` holds an `INDEX.md`
(one row per investigation: date, scope, result, link) and one directory per
investigation, named `YYYY-MM-DD-NNN/`, containing at least `report.md`.

Created once the first source is added; empty for now.
